# Profile: ad

Brand ads, UGC ads, product promos.

- **Structure**: hook (0–2 s) → problem → solution → proof → CTA. End card of
  2–3 s with logo and CTA.
- **Pacing**: a cut every 1–2 s; no dead air.
- **Cleanup**: full — fillers, retakes, long breaths.
- **Music**: energetic; cut on the hits.
- **Subtitles**: burned-in by default (in a feed it starts muted) + `.srt`.
- **Graphics**: price, offer and CTA as cards; brand logo.
- **Extra deliverables**: the main version **plus one alternative-hook version**
  (only the first 2–3 s change; the rest is reused). Offer the rest in one line
  of the delivery: 6/15/30 s cuts and 4:5, 1:1, 16:9. If the request says it's
  for paid campaigns, make the aspect ratios that platform needs without asking.
- **Traps**: offer, price, dates and legal text are checked letter by letter
  against the request or the brief.
- **Color**: level 1 always checked; brand-consistent look (the brand's LUT if there is one, else `natural`); every version and aspect ratio shares the same grade.
